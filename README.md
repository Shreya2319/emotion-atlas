# Emotion Atlas — Static Site

A calm, static website for the Emotion Atlas brand. Pure HTML/CSS/JS — no build step, no dependencies.

## Structure

```
emotion-map-site/
├── index.html        # Homepage: hero, emotion grid, free guides, workbooks (coming soon)
├── emotion.html      # Reusable detail template (reads ?e=FOLDER)
├── manifest.json     # Generated data (emotions, images, guides) — read by the pages
├── data.csv          # Source data
├── assets/
│   ├── style.css     # All styling
│   └── app.js        # Homepage + detail logic, lightbox, carousel
├── images/<EMOTION>/ # ~10 images per emotion (cover = first image)
└── guide/            # 3 free PDF guides
```

## Preview locally

The pages load `manifest.json` with `fetch()`, which browsers block on `file://`.
So you must serve the folder over HTTP. From inside `emotion-map-site/`:

**Python (already on most machines):**
```bash
python -m http.server 8000
```
Then open http://localhost:8000

**Or Node:**
```bash
npx serve .
```

Opening `index.html` by double-clicking will NOT load the emotions (fetch is blocked on file://). Always use a local server.

## If images change

The image filenames are inconsistent, so `manifest.json` is generated by scanning the folders.
If you add/rename images, regenerate it:

```bash
python generate_manifest.py
```

## Deploy to Vercel

This is a zero-config static site.

**Option A — Vercel dashboard (easiest):**
1. Push this folder to a GitHub repo.
2. Go to vercel.com → **Add New → Project** → import the repo.
3. Framework preset: **Other**. Build command: *(leave empty)*. Output directory: `./` (root).
4. Deploy.

**Option B — Vercel CLI:**
```bash
npm i -g vercel
cd emotion-map-site
vercel          # preview deploy
vercel --prod   # production deploy
```

`vercel.json` enables clean URLs. No environment variables or build step needed.

## Notes

- The grid and detail pages are driven entirely by `data.csv` (24 emotions).
- Connected emotions that don't have their own row (Grief, Joy, Loss) render as non-clickable chips.
- The "Related Workbook" button and the three workbook cards are intentional "Coming Soon" placeholders.
